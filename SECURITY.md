# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions.

For this project on GitHub, use the repository's **Security → Report a vulnerability** private reporting flow when it is enabled. If private reporting is not available, contact the maintainers directly using the contact method on the repository organization/profile and include “TunnelNote security report” in the subject.

Include the affected version or commit, the impact, reproducible steps, and any relevant platform details. Do not include real passwords, private keys, vault files, or other users' data in a report.

The maintainers will acknowledge reports as soon as practical, investigate privately, and coordinate a fix and disclosure timeline with the reporter. No response-time guarantee is made until a dedicated security contact and service-level policy are established.
